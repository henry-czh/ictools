# 项目介绍

## 项目功能 
- 支持打开IP-XACT文件
- 支持添加IP-XACT文件到工作区
- 支持删除IP-XACT文件
- 支持保存IP-XACT文件
- 支持导出IP-XACT文件

## 项目结构 
- 项目根目录
  - objects/
    - library/
      - IP/
        - uart_1.0.xml
  - main.py
  - Readme.md

  ## 项目运行
  - 打开项目根目录
  - 运行 main.py

  ## 项目使用
  - 打开IP-XACT文件
  - 添加IP-XACT文件到工作区
  - 删除IP-XACT文件
  - 保存IP-XACT文件
  - 导出IP-XACT文件

  ## 项目注意事项
  - 项目仅支持打开IP-XACT文件，不支持创建IP-XACT文件
  - 项目仅支持打开IP/IP目录下的XML文件
  - 项目仅支持保存IP/IP目录下的XML文件  

  ## 项目依赖
  - PyQt5
  - lxml    

  ## IP Library
  - 项目仅支持打开IP/IP目录下的XML文件
  - 项目仅支持保存IP/IP目录下的XML文件

  配置/Library库配置 中允许指定多个Library目录，可以增加和删除Library目录。
